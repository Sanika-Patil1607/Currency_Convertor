# 💱 Currency Converter

A simple and responsive Currency Converter web app that allows users to convert currencies in real-time using live exchange rates.

## 🚀 Features

- 🌍 Convert between multiple currencies
- 🔄 Real-time exchange rates using API
- 🇺🇳 Country flags for better UI
- 🎨 Modern UI with animated gradient background
- 📱 Fully responsive design
- ⚡ Fast and lightweight

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (with animations & responsive design)
- JavaScript (ES6)
- Currency API (Open ER API)

---

## 🔗 API Used

- https://open.er-api.com/v6/latest/USD


---

## ⚙️ How It Works

1. Select **From Currency**
2. Select **To Currency**
3. Enter the amount
4. Click on **Convert**
5. Get instant converted value
